# KIDEX Product Roadmap

KIDEX is evolving from a simple assessment tool into a comprehensive Bio-Psycho-Social Sport Ecosystem.

## Phase 1: MVP (Current)
- [x] Rapid & Full Assessment Modes
- [x] Bio-Psycho-Social Scoring & SKI Calculation
- [x] Evidence Image Support
- [x] Basic Persistence (MongoDB)
- [x] Multilingual Support (HU/EN)
- [x] Localized Routing & Structured Navigation

## Phase 2: Professionalization (In Progress)
- [x] **Automatic Age Categorization**: Intelligent age group assignment based on birthdate.
- [/] **User Rights Management**: Implementing RBAC (Admin, Conductor, Observer).
- [/] **Settings Management**: Centralized management of Conductors, Observers, and Locations.
- [/] **UI/UX Polishing**: Elimination of technical jargon and improved layout for "rich functionality".

## Phase 3: Enhanced Data & Children Management
- [ ] **Children Centralized Profiles**: Comprehensive data management for children, including historical tracking.
- [ ] **Longitudinal Tracking**: Track a child's development over multiple assessments with comparison charts.
- [ ] **Dynamic Scoring Models**: Configurable calculations for AVG scores based on different dimensions.
- [ ] **Standards & Benchmarking**: Setup of performance standards and optimal measures for age groups.

## Phase 4: Advanced Functionality & Offline
- [ ] **Advanced PDF Reporting**: Automated generation of high-fidelity reports for parents.
- [ ] **Offline Capability (PWA)**: Support for conducting assessments in areas with unstable internet.
- [ ] **Parent Portal**: Secure access for parents to view results and recommendations.

## Phase 5: Ecosystem Integration
- [ ] **Club Dashboard**: Aggregated data for sport clubs to optimize training programs.
- [ ] **API Integration**: Connect with existing club management systems.
